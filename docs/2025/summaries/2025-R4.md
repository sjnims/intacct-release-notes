# 2025 R4 Executive Summary

Sage Intacct 2025 R4 (November 7, 2025) makes Close Workspace generally available in the UK and US, expands Copilot into email drafting and help search, and adds meaningful depth to Fixed Assets, Consolidation, and Contracts. The most urgent item for US customers: the Authorize.net and PayPal customer payment integrations were retired on release day, requiring an immediate move to an alternative such as Versapay. Developers should also note that all new objects and features are now REST-only — the XML API is in maintenance mode.

## Breaking Changes & Deprecations

- Authorize.net and PayPal customer payment integrations were retired on November 7, 2025; Versapay is the recommended replacement (US only).
- All new objects and features will ship in the REST API only — the XML API is supported but no longer receiving new functionality.
- Anonymous user "slide-in" to a Console-managed instance is no longer permitted, in order to preserve a clean audit trail.
- The Subscribe tab has been removed from the Consoles Instance Setup Wizard; subscriptions are now managed inside each instance.
- Permissions changed for Consoles, Contracts, and Time (Sage Intelligent Time), and sandbox instance naming conventions were updated.

## Action Required

- US companies still using Authorize.net or PayPal for customer payments must migrate now — those integrations are already off.
- Review 1099 setup ahead of season: excessive golden parachute payments move from 1099-MISC Box 14 to 1099-NEC Box 3, and entity contacts must be assigned if issuing separate 1099s per entity (US only).
- Confirm the changed Consoles, Contracts, and Time permissions still match your role design before month-end close.
- Audit any integrations or scripts that depend on updated sandbox names or on XML API-only development plans.
