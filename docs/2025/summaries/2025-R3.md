# 2025 R3 Executive Summary

Sage Intacct 2025 R3 centers on close automation and AP/purchasing automation, with Sage Copilot Close Workspace entering Early Adopter and Close Automation reaching general availability (UK, US). Two items need near-term attention: Authorize.net and PayPal customer payment integrations retire November 7, 2025 (US), and enhanced lists become the default UI experience for all companies. US customers also gain embedded vendor payments via MineralTree and eProcurement punchout catalogs.

## Breaking Changes & Deprecations

- Authorize.net and PayPal customer payment integrations retire November 7, 2025; Sage recommends migrating to Versapay (US).
- Warehouse transfer transaction definitions replace Inventory transfer transaction definitions (AU, CA, ZA, UK, US).
- All new objects and features now ship only in the REST API; the XML API is supported but frozen for new functionality.
- Enhanced lists become the default list experience for all companies, changing day-to-day navigation for users.
- Entity-level funds transfers now require at least one bank account owned by that entity, which may break existing transfer setups.
