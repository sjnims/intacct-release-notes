# User interface changes

In this release, we updated the following aspects of the user interface in Sage Intacct for clarity and consistency.

| Product area   | Change description                                                       | Old UI                                                         | New UI                                                        |
| -------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------- |
| Enhanced lists | Include entity records checkbox visible on list page for enhanced lists. | Include entity records checkbox was only in the Filter dialog. | Include entity records checkbox is directly on the list page. |
