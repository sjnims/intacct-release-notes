# Updates to Sage Planning

Sage Planning is the new name for Enhanced Sage Intacct Planning.

Sage Intacct Planning is a separate product. The information in this article does not apply to it.

This release includes the following updates to improve your Sage Planning experience.

- **Apply account groups**: Select the top-level account groups to use throughout your plans. Each account group that you select includes the entire underlying hierarchy of that group. [Learn about managing account groups](https://help.intacct-planning.com/core/Topics/account-groups.htm#manageaccountgroups)
- **Add new hires and edit employee details**: Keep your future headcount accurate in workforce planning. [Learn about adding new hires and editing employee details](https://help.intacct-planning.com/core/Topics/edit-employees.htm)

## Learn about Sage Planning

For more information about Sage Planning, including how to subscribe, [contact your Sage Intacct account manager](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Contact_your_account_manager).

To keep up with the latest releases, new developments, and feature improvements, see [what's new in Sage Planning](https://help.intacct-planning.com/core/Topics/whats-new.htm).
