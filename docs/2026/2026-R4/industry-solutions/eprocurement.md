# Enhancements for Sage Intacct eProcurement

This release includes the following updates to improve your Sage Intacct eProcurement experience.

- **Purchase lifecycle control dashboard**: Use this dashboard to monitor and track purchases that have not been completed.

  If suppliers send confirmation, shipping, or invoice requests to eProcurement, this information is included in the dashboard.

- **Department-based requisition transactions**: You can set up distinct requisition types for specific departments (for example, IT purchase orders for the IT department, and general purchase orders for the back-office). This lets you have different approval workflows for different departments even if they're shopping at the same vendor.
- Map GL Groups to items that were created as part of an incoming message from a supplier.
