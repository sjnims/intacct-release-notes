At Sage Intacct, we get how vital it is to have in-depth and best practice learning available to make sure you get the most out of Intacct.

- Access new and updated self-paced, on-demand courses that guide you through specific tasks and features.
- View demo videos to help you get up and running on a variety of tasks.

## New and updated training courses

You can find these new and updated training courses at [Sage University](https://sageu.com/SageIntacct/).

You'll need to [log in to Sage University with your Sage account](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Connect_Sage_University).

| Application                            | Course                                                                                                                                                                                                                                                | Description                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Company                                | How to use the Import service                                                                                                                                                                                                                         | Explore the import service in Sage Intacct and its key capabilities for managing data imports. This course covers locating import templates, mapping file fields to SI fields, and reviewing data before import to help ensure accurate and efficient processing.                                                                |
| Managing Users, Roles, and Permissions | (Updated content) Learn how to create and manage users, roles, permissions, and user groups in Sage Intacct. This course covers user access and administrative privileges, along with best practices for maintaining access across your organization. |
| Order Entry                            | Using Revenue Management with Order Entry                                                                                                                                                                                                             | Coming soon! Explore how Sage Intacct generates revenue recognition schedules from transactions and how you can review and manage those schedules. Learn about common tasks such as posting revenue and, depending on your permissions, editing, holding, resuming, reallocating, and terminating revenue recognition schedules. |
| Reporting                              | Building Financial Reports                                                                                                                                                                                                                            | (Updated final activity) This course is designed to teach you the essentials of using the Financial Report Writer to create and manage financial reports. In addition, this course teaches you how to create graphs, dashboards, and performance cards to provide insight into your organization's performance.                  |
