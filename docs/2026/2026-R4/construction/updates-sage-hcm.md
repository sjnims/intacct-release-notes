This release includes the following updates to improve your Sage Human Capital Management (HCM) experience.

## Vertex integration modernization

Sage HCM modernizes the connection to Vertex, helping payroll tax and geolocation services remain reliable, supportable, and ready for evolving requirements.

### Key benefits

- **Modern tax service connectivity**: Payroll tax processing now uses the modern Vertex REST interface, replacing legacy communication patterns with a more maintainable integration.

- **Clearer operational visibility**: Enhanced tracing helps support teams track requests through Vertex and identify where processing issues occur.

- **Stronger response handling**: Improved validation and error handling provide clearer outcomes when tax or geolocation data cannot be processed.

- **Greater payroll confidence**: Additional compatibility and parity improvements help provide more consistent tax calculation results.

### How it works

Customers continue to use familiar payroll workflows while benefiting from a more resilient underlying service. The modernization reduces the risk of interruptions and improves the handling of complex tax scenarios.

For employers operating across multiple jurisdictions with complex tax requirements, these improvements support accurate calculations and reduce the need for manual intervention.

## Location history

Location history gives employers greater visibility into where mobile employees perform work. This feature also provides employees with a clear experience when location collection is active.

### Key benefits

- **Location collection aligned with work activity**: The mobile application can collect periodic location information while an employee is actively clocked in and stop collection when the applicable work activity ends.

- **Resilient mobile operation**: Location information is retained during connectivity interruptions and synchronized when the device reconnects.

- **Employee controls and transparency**: Employees can review location settings in their profile and receive clear guidance when permissions or device settings need attention.

- **Location history in Who is Working**: Authorized managers can access an employee's location history from the Who is Working experience, including mapped location points and supporting work context.

- **Configurable employer controls**: Employers can enable location history and decide how frequently to collect applicable location information.

### How it works

When enabled, location history collects periodic location information while employees are actively clocked in. Employers can use this information to help validate time and attendance activity, support accountability, and resolve questions about where work occurred.

Employees can see when location collection is enabled and review their location settings. Location collection is tied to active work periods and stops when the applicable work activity ends.

For more information, go to [Manage Work Locations.](https://help.criterionhcm.com/hc/en-us/articles/210952263-Manage-Work-Locations)

## Sage Intacct standard dimension support

The connection between Sage HCM and Sage Intacct is now stronger with structured support for standard financial dimensions.

### Key benefits

- **Native dimension synchronization**: Sage HCM can synchronize supported Sage Intacct dimensions through the standard Intacct application.

- **Dedicated support for key dimensions**: Use structured support for Customer, Class, Item, and Department information.

- **Financial context carried through Sage HCM**: Associate Customer and Class information with projects, and flow Item information through timesheet and payroll processing.

- **Improved synchronization results**: Implementation teams receive clearer information about synchronization outcomes, making configuration and troubleshooting easier.

- **Stronger foundation for GL integration**: Use standardized dimension records to create a consistent foundation for GL exports, job costing, and future accounting integration enhancements.

### How it works

Standard dimension support provides a more consistent approach for connecting Sage HCM and Sage Intacct. Standard dimensions rely less on generic code tables, custom fields, or one-off back-end configuration.

This reduces setup effort, preserves important accounting context across workflows, and creates a stronger connection between workforce activity and financial reporting.
