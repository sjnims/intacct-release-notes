# Attachment permissions for Client users

[About Client user type](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=About_client_user_type)

[Permissions for attachments](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Attachment_permissions_overview)

[Company permissions](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Company_permissions)

sAGE iNTACCT advisory

Assign attachment permissions to Client users so they can include supporting documents with transactions and journal entries. This helps Client users complete transaction entry without relying on another user to add the attachments.

![](https://www.intacct.com/ia/docs/en_US/releasenotes/Resources/Images/2026/2026-R4-images/2026-R4-SIA-client-user-attachment-permissions.png)

## Key benefits

- **Complete transaction records**: Client users can enter complete information, including relevant attachments.

- **Simplified transaction entry**: Transaction entry can now be handled by a single user, without the need to split responsibilities.

## How it works

A Business user with admin privileges assigns the appropriate **Attachment folders** and **Attachments permissions** to a Client user under the **Company** application. The Client user can then work with attachments based on those permissions and the application permissions assigned to them.

For detailed instructions, see [Assign permissions to users](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Assign_permissions_users).

## Good to know

Attachment permissions do not provide access to every transaction or journal entry. The Client user must also have the [application permissions required](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Attachment_permissions_overview) to use attachments for the relevant record.
