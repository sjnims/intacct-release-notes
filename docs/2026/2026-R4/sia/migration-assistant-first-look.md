# Migration Assistant simplifies onboarding new clients

Accelerate the process of bringing new clients onto Sage Intacct using our new Migration Assistant. The initial release allows **Sage Intacct Advisory** partners to efficiently and accurately transfer a client's existing data from QuickBooks to Intacct, including chart of account and dimension mapping, data cleansing and deduplication, reconciliation, and historical transaction migration.

## Key benefits

**Make data Intacct\-ready**: Structure, map, and prepare legacy data so each migration begins from a stronger foundation.

**Accelerate implementation**: Reduce manual effort through AI-assisted mapping, migration, validation, and reconciliation workflows.

**Go live with confidence**: Review what's loaded, resolve exceptions, and reconcile results before sign-off.

## Good to know

SIA partners can find additional information and instructions for using Migration Assistant in Highspot.
