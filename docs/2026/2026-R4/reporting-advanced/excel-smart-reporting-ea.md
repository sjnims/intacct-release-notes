# Connected Reporting for Excel—Early Adopter

We're excited to offer a new report writing option that lets you use Sage Intacct financial data to build reports directly in Microsoft Excel. The financial data remains linked to the Excel report so that you can refresh it with the latest information as needed. Sage Intacct security permissions are applied to the linked data through Excel.

## Key benefits

**Stay in your existing workflow:** Initiate Excel report writing directly from Sage Intacct for a seamless, connected reporting experience.

**Simplify Excel report creation:** Create and refresh reports through a guided, step-by-step experience or with natural language AI prompts.

**Maintain governance and control:** Existing Sage Intacct permissions and security settings are automatically honored to help ensure appropriate data access.
