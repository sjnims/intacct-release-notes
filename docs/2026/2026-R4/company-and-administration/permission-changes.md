# Permission changes

[Assign user permissions for new features (4:05)](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_4/Company_and_Administration/2026-R4-permission-changes.htm#)

company & administration

You can find information about the permissions needed for each new feature in the Permissions and other requirements section of its associated release note.

## Updated

We've updated aspects of the following permissions.

### Expenses

When you reimburse employee expenses through AP bills or payroll, the following permissions are updated:

- **Expense types**: List, View, Add, Edit, Delete

  Previously, this permission allowed you to manage expense types only. Now, this permission allows you to [manage employee advances](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_4/Expenses/2026-R4-new-expense-reimbursement-options.htm) and expense types.

### Time—Sage Intelligent Time

- **Staff timesheets**: List, View, Add, Edit, Delete

  Previously, this permission allowed you to manage staff timesheets and staff time clocks. Now, this permission allows you to [manage crew timesheets](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_4/Time/2026-R4-SIT-crew-timesheets.htm), staff timesheets, and staff time clocks.

## Added

All new permissions are automatically off by default, unless otherwise noted.

### Company

Use the new License usage page to view user counts by type.

- **License usage**: List, View

Assign attachment permissions to Client users.

- **Attachment folders**: List, View, Add, Edit, Delete

- **Attachments**: List, View, Edit, Delete

### Expenses

When you remit employee expenses through payroll, the following permissions are added:

- **Remit expense reports for payroll**: List, View, Remit, Reverse remit

  Allows you to [remit employee expenses](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_4/Expenses/2026-R4-new-expense-reimbursement-options.htm) through your external payroll.

### Order Entry

- **Quantity entries**: List, View, Add, Edit, Delete

  Allows you to [manage quantity entries for billing groups](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_4/Order_Entry/2026-R4-OE-billing-group-tier-quantity.htm).

## Removed

### Expenses

When you reimburse employee expenses through AP bills or payroll, the following permissions are removed:

- **Pending reimbursements**: List, View, Edit, Delete

- **Posted reimbursements**: List, View, Void

- **Approve reimbursements**: List, Level 1 - 6

- **Select to reimburse**: Run

- **Expense summaries**: Reverse expenses, Reclass expense

- **Pay in advance**: Run

- **Posted advances**: List, View, Void

- **Expense adjustments**: Reverse, Reclass

- **Employee expense aging report and graphs**: Run
