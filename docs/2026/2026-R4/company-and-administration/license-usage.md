# Review license usage by user type

Use the new **License usage** page to quickly view user counts by type in one place. Instead of filtering the Users page multiple times, administrators can review current usage and compare it against licensed limits to help manage subscriptions and avoid unexpected charges.

![](https://www.intacct.com/ia/docs/en_US/releasenotes/Resources/Images/2026/2026-R4-images/2026-R4-company-license-usage.png)

## Key benefits

- **Quick visibility**: User types and totals are visible in one step.

- **Reduced manual effort**: Previously, viewing the number of users by type required navigating to the Users page and applying individual filters for each user type.

- **Easier contract compliance**: Ensure that you’re remaining within the usage limits of your Sage Intacct license, avoiding overage charges.

## How it works

Navigate to the new page at **Company > Setup > Configuration > License usage**.

Use this information to evaluate license utilization before adding users, during periodic reviews, or when investigating potential overages.
