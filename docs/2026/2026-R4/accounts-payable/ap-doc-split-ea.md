# Split multi-page documents into individual transactions with AP Automation—Early Adopter

[Split an uploaded document into separate transactions with AP Automation](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=AP_auto_doc_split)

accounts payable

Upload a document containing multiple transactions and automatically split it into separate transactions for processing in AP Automation.

## Key benefits

- **Save time**: Upload documents with multiple transactions without splitting them first.

- **Automate transaction creation**: Create individual transactions from transactions detected in the uploaded document.

- **Maintain visibility**: Review split transactions while retaining access to the original document.

## How it works

1.  On the Automated transactions list, select **Upload**.

2.  Select **Enable smart split** and continue to upload the file and create bills.

3.  AP Automation analyzes the file, separates individual transactions, and creates child transactions for processing.

4.  Sage Intacct creates a draft transaction and replaces it with the resulting transactions when processing is complete.
