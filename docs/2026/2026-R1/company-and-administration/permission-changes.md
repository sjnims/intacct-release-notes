# Permission changes

[Assign user permissions for new features (4:05)](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_1/Company_and_Administration/2026-R1-permission-changes.htm#)

company and administration

You can find information about the permissions needed for each new feature in the Permissions and other requirements section of its associated release note.

## Updated

We've updated aspects of the following permissions.

### Time—Sage Intelligent Time

- **Time preferences**: View

  Previously, this permission enabled the following pages: Time gathering, Overtime, Notifications, Time tracking, Security, Advanced, and Download app. Now, this permission enables the following pages: Time gathering, Overtime, Notifications, Time tracking, Security, Advanced, Download app, Time settings, and Geofences.

## Added

All new permissions are automatically off by default, unless otherwise noted.

### Fixed Assets Management

- **Roll Forward report**: Run

  Allows you to run the [Roll Forward](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_1/Fixed_Assets/2026-R1-fam-roll-forward-report.htm) report.

### Order Entry

- **Billing groups**: List, View, Add, Edit, Delete

  Allows you to create and manage [billing groups](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_1/Order_Entry/2026-R1-billing-groups.htm).

### Projects

- **Projects**: Manage projects

  Allows for bulk updates to project records.
