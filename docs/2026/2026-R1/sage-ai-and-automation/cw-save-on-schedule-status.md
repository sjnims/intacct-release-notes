# Improved drill-down capability in Close progress monitor

[About Close progress monitor](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=close_progress_monitor)

Sage AI and Automation

In the Close progress monitor, you can now drill down to task lists from the task status tiles and the Progress by Task Category graph.

![Close progress monitor.](https://www.intacct.com/ia/docs/en_US/releasenotes/Resources/Images/2026/2026-R1-images/2026-R1-ca-close-prog-monitor-drill-down.png)

## How it works

To view the page, go to **Close Workspace** > **All** > **Close progress monitor**.

On the task status tiles that show the number of tasks with that status, select the number to view a list of the associated tasks.

In the Progress by Task Category chart, select a category name to view a list of the associated tasks.
