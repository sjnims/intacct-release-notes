# Introducing multi-entity and multi-currency support in projects

[Sage Intacct EMRConnect](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Sage_Intacct_EMR_connect)

INDUSTRY SOLUTIONS

Sage Professional Services Automation (PSA) now aligns projects more closely with Sage Intacct through new multi-entity and multi-currency capabilities. These enhancements help keep entity, client, and currency data consistent across both products, reducing manual entry and providing finance teams with a single, reliable source of truth.

## Support for multi-entities in projects

You can now sync Sage PSA projects with Sage Intacct entities and clients when you create projects. When you create a project in Sage PSA, a corresponding project is automatically created in Sage Intacct and linked to the selected entity and client, ensuring both products remain aligned from the start.

## Support for multi-currency projects

Project currencies now remain synchronized between Sage PSA and Sage Intacct, and the number of supported currencies has increased significantly. Because currency affects downstream financial calculations throughout your ERP system, these changes help reduce reconciliation effort and potential finance errors.

### Sync project currencies between Sage PSA and Sage Intacct

You can sync a project's currency from Sage PSA to the Project currency field on the matching project in Sage Intacct. A project's currency in Sage PSA is determined by its rate card. That currency is then synced to the corresponding project in Sage Intacct, ensuring consistency across both products.

### Additional Forecast currencies from Sage Intacct

Forecast now supports additional currencies sourced from Sage Intacct, expanding the list of available currencies in Sage PSA. Previously, Sage PSA supported 31 currencies while Intacct supported approximately 150 currencies. Forecast now supports the full Sage Intacct currency catalog, providing users access to 151 currencies.

If you have not subscribed to Sage Professional Services Automation, [contact your Sage Intacct account manager](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Contact_your_account_manager).
