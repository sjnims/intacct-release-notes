# Enhancements in Sage Expense Management

Sage Expense Management

Sage Expense Management (SEM) now includes enhancements that help simplify credit card reconciliation and strengthen report and card transaction controls. SEM also improves management of delegated access, reduces repetitive expense updates, and makes navigating Admin Settings faster and easier.

## Reconciliation module (Beta)

You can now reconcile card transactions in Sage Expense Management against transactions on your card statements. The Reconciliation feature provides a centralized workflow to review, match, and resolve differences between statement data and expense records.

Configure reconciliation using either calendar-month periods or custom statement periods. After a statement is uploaded, SEM automatically compares statement transactions against existing expenses and groups them based on reconciliation status.

Review matched transactions, identify transactions missing from either the statement or Sage Expense Management, and take actions, such as matching, importing, ignoring, or deleting transactions. The feature also supports reconciliation of transactions with multiple potential matches.

After reconciliation is completed and closed, reconciled expenses are marked accordingly, and their amount date can no longer be edited.

For more information, go to [Reconcile your cards using the Reconciliation feature](https://www.fylehq.com/help/en/articles/13609035-beta-reconcile-your-cards-using-the-reconciliation-feature).

## Card transaction edit controls

Improve visibility and control over card transaction updates.

Admins can now enable a setting that prevents spenders from editing the amount or date on expenses linked to card transactions. Spenders can continue to edit manually created expenses and split card expenses, provided that the total of all splits matches the original transaction amount. Admins retain the ability to edit all expenses.

SEM also now indicates when the amount or date on a linked card expense and has been modified from the original card transaction value. For organizations using Real-Time Feeds (RTF), SEM also provides additional information about pending transactions and how they work.

For more information, go to [Managing corporate card transactions](https://www.fylehq.com/help/en/articles/4934222-managing-corporate-card-transactions).

## Access delegation controls

Control the level of access granted to delegates.

You can now select the level of access a delegate receives when access delegation is configured. This provides greater control over what actions delegates can perform on your behalf.

The following access types are available:

- Submit

- Approve

- Submit & Approve

- Unrestricted

Each access type provides a different level of access to expenses, reports, and approval actions. The selected access type applies across both the web and mobile applications.

SEM also prevents delegates from approving their own reports, even when they have Approve or Unrestricted access.

For more information, go to [Enabling delegation for employee accounts](https://www.fylehq.com/help/en/articles/2317384-enabling-delegation-for-employee-accounts) and [Access delegation](https://www.fylehq.com/help/en/articles/3808267-access-delegation).

## Edit multiple expenses at the same time

Update multiple expenses in a single action.

You can now edit multiple expenses simultaneously when the same updates need to be applied across several expenses, reducing the need to update each expense individually.

Admins can edit multiple expenses from the Business Expenses page and within expense reports. Approvers can edit multiple expenses within expense reports assigned to them for review.

You can update supported fields, such as Category or GL code, Cost center, Project, Custom fields, Merchant, Purpose, and Billable status across up to 50 expenses at a time.

For more information, go to [Edit multiple employee expenses as an Admin](https://www.fylehq.com/help/en/articles/15132176-edit-multiple-employee-expenses-as-an-admin) or [Edit multiple team expenses at once as an Approver](https://www.fylehq.com/help/en/articles/15131092-edit-multiple-team-expenses-at-once-as-an-approver).

## In-line editing of expenses (Beta)

Review and update expenses directly from the list view.

You can now review and edit expense details directly from the expense list view without opening each expense individually. In-line editing is available on the Business Expenses page and within expense reports, allowing you to make quick corrections while reviewing expenses.

You can update editable expense fields directly from the row and save changes instantly from the list view.

For more information, go to [Edit expenses directly from the list view](https://www.fylehq.com/help/en/articles/14309979-edit-expenses-directly-from-the-list-view-beta).

## Search in Admin Settings (Beta)

Find settings and configuration pages more quickly.

You can now use Search in Admin Settings to quickly locate pages, sections, and settings without manually browsing through the sidebar. A new search bar is available at the top of the Admin Settings sidebar and can also be opened using the / keyboard shortcut.

Search results are grouped into categories, making it easier to navigate directly to the page or setting that you are looking for.

If you have not subscribed to Sage Expense Management, [contact your Sage Intacct account manager](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Contact_your_account_manager).
