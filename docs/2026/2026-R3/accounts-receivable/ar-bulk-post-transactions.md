# Post multiple invoices and adjustments at the same time

Save time and reduce manual effort by posting invoices in bulk when you turn on enhanced lists. Previously, you could only post these transactions one at a time.

## Key benefits

- **Save time and effort**: Update multiple transactions at once instead of modifying each one manually.

- **Scale with ease**: Efficiently manage large volumes of transactions as your organization grows.

## Permissions and other requirements

| Subscription          | Accounts Receivable                   |
| --------------------- | ------------------------------------- |
| Regional availability | All regions                           |
| User type             | Business                              |
| Permissions           | Invoices: List, View, Add, Edit, Post |
