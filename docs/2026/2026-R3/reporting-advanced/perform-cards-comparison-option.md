# Compare-to options for additional reporting periods in performance cards

[Add performance cards to dashboards](https://preview.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=TOC_performance_cards)

Reporting and insights

We've added more options for using dashboard performance cards to compare data across cumulative reporting periods.

![](https://preview.intacct.com/ia/docs/en_US/releasenotes/Resources/Images/2026/2026-R3-images/2026-R3-rpt-perf-cards-compare.png "Dashboard with performance cards showing the average AP and AR balance for this year through the current month with a comparison against the prior period. ")

## Key benefit

**Improved trend insights**: See how current performance tracks against historical data to better understand growth, decline, and seasonality.

## How it works

When you select one of the following reporting periods, you can now use the prior period for comparison by selecting **Period** in the **Compare to** field.

- Current Year Through Current Month

- Current Year Through Prior Month

- Current Year Through Prior Quarter

- Fiscal - Current Year Through Current Month

- Fiscal - Current Year Through Prior Month

- Fiscal - Current Year Through Prior Quarter

![Component properties window for a performance card. The Compare to field is circled.](https://preview.intacct.com/ia/docs/en_US/releasenotes/Resources/Images/2026/2026-R3-images/2026-R3-gl-performance-card-comparison.png)
