# User interface changes

In this release, we updated aspects of the user interface throughout Sage Intacct for clarity and consistency.

| Product area                                                                             | Change description                                                                                             | Old UI                                                                                | New UI                                               |
| ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Company                                                                                  | We renamed the subscription for Construction payroll.                                                          | Construction payroll                                                                  | Sage Intacct Construction Payroll, powered by Struxi |
| We renamed the subscription for Real Estate.                                             | Real Estate                                                                                                    | Sage Intacct Real Estate                                                              |
| We changed a label in Company Information for clarity.                                   | Allowed email addresses                                                                                        | Allowed sender email addresses                                                        |
| Cash Management                                                                          | To ensure clarity, we changed the status descriptions for an account's Last reconciliation type.               | Bank feed Import Manual                                                               | Banking cloud Classic import Manual                  |
| We changed the date display for Last bank feed date and Last bank feed transaction date. | These fields displayed dates if the account was last reconciled using either a bank feed or a BTA file import. | These fields display dates only if the account was last reconciled using a bank feed. |
