# Updates in Sage Intacct Paperless

[Sage Intacct Paperless](https://preview.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Paperless_for_construction)

CONSTRUCTION

Improve and modernize your paper-heavy accounts payable document workflow. Sage Intacct Paperless is an intelligent, automated solution that lets you capture, index, route, and store documents in one secure place.

In this release, you can find these enhancements:

- **Improvements to allocations and allocation rules**: You can now preconfigure invoice lines and values and drop that coding onto the invoice for recurring invoices via allocations. Also, you can set up rules based on other invoice values to automatically trigger which allocations are applied to an invoice.
- **New budget worksheet modals in invoice entry**: Display commitment and invoice summary information, including **Original Committed Amount**, **Amount Invoiced to Date**, **Outstanding Amount in Paperless**, and **Remaining Balance**.
- **Improved help**: A new help system includes a better search feature so you can find information in help more easily.
- **Updated look and feel**: New light and dark themes are available, and updates to many pages provide a more consistent look and feel throughout the application.
- **Matched receipt report in credit card importer**: When working in the "in progress" view, you can use this report to get a top-down view of which invoices and lines have matched receipts when doing 2-way matching.
- **Enhancements in Report Scheduler:**
  - Add multiple recipients to receive a report under the same report schedule configuration.
  - Set dynamic date parameters like **Month Begin**, **Month End**, and **Current Date** so that scheduled reports contextually adapt to future time periods when reports are generated.
  - A new administrative view lets administrators monitor and configure scheduled reports for other users.
- **Reverse conversion of purchasing invoices**: Transactions created by converting a purchasing invoice can be converted back into their original purchasing invoice state.
- **Custom Tax Solutions:**
  - You can use a custom tax solution with either the advanced or simple tax engine.
  - When using a custom tax solution with the advanced tax engine, you can default the tax schedule based on **Job**, **Cost Code**, and **Cost Type**.
- **Customize quicklist views**: For all quicklists, you can sort, hide, and show columns; and expand the grid to a larger view.
