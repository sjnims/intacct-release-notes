# User interface changes

In this release, we updated aspects of the user interface throughout Sage Intacct for clarity and consistency.

| Product area                                                               | Change description                                                                                                                                                    | Old UI                        | New UI                           |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | -------------------------------- |
| Accounts Payable                                                           | On the Configure Accounts Payable page, we moved three remittance options to a new Remittance section.                                                                | Enable functionality section  | Remittance section               |
| Company                                                                    | We renamed the subscription for Close Automation.                                                                                                                     | Sage Copilot Close Automation | Sage Intacct Close Automation    |
| Fixed Assets Management                                                    | We simplified two labels.                                                                                                                                             | Depreciation schedule entry   | Depreciation entry               |
| Journal posting rule                                                       | Journal rule                                                                                                                                                          |
| We renamed a section on assets to better reflect its contents.             | CIP information                                                                                                                                                       | Capitalization                |
| We renamed a tab on assets to be consistent with the naming of other tabs. | Transfer history                                                                                                                                                      | Transfers                     |
| We renamed two buttons to align with a new configuration setting.          | Place back in review                                                                                                                                                  | Revert place in service       |
| Place back in service                                                      | Revert full disposal                                                                                                                                                  |
| General Ledger                                                             | We changed a field on the General Ledger accounts page. We've also added a new Reporting category type field that you can use to filter the Reporting category field. | QuickStart category           | Reporting category               |
| Inventory Control, Purchasing, Order Entry                                 | On Item records, we changed a label to better align with the related configuration page setting.                                                                      | Unit cost precision           | Decimal places for unit cost     |
| Purchasing                                                                 | We renamed two columns in the Subtotals section to better reflect their purpose.                                                                                      | Value                         | Transaction value and Base value |
| Total                                                                      | Transaction total and Base total                                                                                                                                      |
