# Restricted file types for attachments

[Add an attachment](https://preview.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Add_an_attachment)

[Field descriptions: Attachments](https://preview.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=FBF_attachments)

Company

To improve security, certain file types can no longer be uploaded as attachments. This change helps prevents potentially harmful files from being added.

## What's changed

The following file types are no longer supported for attachment uploads.

- .bat

- .cmd

- .com

- .dll

- .dmg

- .exe

- .iso

- .jar

- .msi

- .ps1

- .sh

- .sys

- .vbs

- .vhd

## Why the change

Restricting certain executable and system file types helps protect companies by reducing the risk of accidental or malicious file uploads.

## Good to know

This change does not affect existing attachments and upload performance remains the same.

## Permissions and other requirements

| Subscription          | Company                 |
| --------------------- | ----------------------- |
| Regional availability | All regions             |
| User type             | Business                |
| Permissions           | Attachments: List, View |
