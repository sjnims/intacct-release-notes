# New permissions

[Assign user permissions for new features (4:05)](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_2/Company_and_Administration/2026-R2-permission-changes.htm#)

company and administration

You can find information about the permissions needed for each new feature in the Permissions and other requirements section of its associated release note.

## Added

All new permissions are automatically off by default, unless otherwise noted.

### Order Entry

- **Invoice runs**: List, View

  Allows you to view [invoice runs for billing groups](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_2/Order_Entry/2026-R2-billing-groups.htm).

- **Individual charges**: List, View, Add, Edit, Delete

  Allows you to create and manage [individual charges for billing groups](https://www.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_2/Order_Entry/2026-R2-billing-groups.htm).
