The Sage Intacct import service continues to expand, making it easier to bring more of your data into Intacct using a consistent, guided import experience. In this release, we’re introducing additional imports and updated availability statuses, giving you access to more data imports.

The import service provides a structured workflow for loading data, mapping fields, validating results, and correcting errors before you commit changes. As we grow support across Intacct areas, you can rely on the same import experience, regardless of the type of data you’re working with.

## Key benefits

-   **Reduced manual effort:** No more manual data tweaks. Describe the changes that you want to see and let the AI agent to do the heavy lifting.
    
-   **Improved data accuracy:** Preview and rollback features help ensure that your data is correct before it’s imported into Intacct.
    
-   **Increased productivity:** Easily handle complex mapping scenarios, like splitting a full name into first, middle, and last names, or combining columns to create new values.
    

## What's changed

The following imports are either newly added to the import service or have had their status updated. For example, an updated status could mean moving from Early Adopter to General Availability.

Early Adopter and General availability imports are available to all users with permissions for the corresponding Intacct areas. **Beta** imports are available only to users enrolled in the [Beta program](https://preview.intacct.com/ia/docs/en_US/releasenotes/2026/2026_Release_2/Company_and_Administration/2026-R2-import-service.htm#Join).

View all available imports at [About the import service](https://preview.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Import_Service_overview).
