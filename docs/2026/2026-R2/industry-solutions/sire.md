# Enhancements in Sage Intacct Real Estate

[Sage Intacct Real Estate](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=si-real-estate)

Industry Solutions

Sage Intacct Real Estate adds property management functionality to Sage Intacct. The solution features a unique data structure that puts the lease document at the center of your workflow, making it flexible enough to accommodate virtually any lease agreement. Real Estate also tracks other business-critical details related to your properties and offers multiple billing options.

Sage Intacct Real Estate is an additional subscription. Your company must be subscribed to the core applications and Web Services to use Sage Intacct Real Estate. To learn more, contact your [Sage Intacct account manager](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Contact_your_account_manager).

## Improved tenant ledger

The following improvements make transaction data easier to read, reconcile, and audit:

- Column headers in the journal now match the labels in the Create Tenant Ledger page: **Transaction Date** and **GL Posting Date**.
- The **Beginning Balance** and **Ending Balance** columns have been replaced with a single running **Balance** column. Each month starts with a Balance Forward line showing the opening balance, followed by a Balance figure after every transaction.
- Payment Number (PAY-…) now appears in the **Check # or ID** column for invoice payments. Advance application rows show the advance reference number in that same field.
- You can drill down to records in Sage Intacct by selecting invoice numbers, payment numbers, adjustment numbers, and advance reference numbers.
- Zero-dollar values ($0.00) no longer appear in the ledger — empty fields are shown as blank. If there are no transactions for the selected period, this is clearly indicated.
- The base currency is now shown beside the **Charges**, **Payments**, and **Balance** columns.
- The tenant ID is now displayed along with the tenant name in **From/To Tenant** fields, consistent with how it appears in Intacct.

## Enhanced lease activation — invoice per period

Activating a back-dated lease now generates a separate invoice for each elapsed billing period, instead of a single lump-sum charge. This gives lease administrators accurate monthly revenue recognition and eliminates the need for manual workarounds.

### Key benefits

- An activation preview shows the date, description, and amount for each pending invoice so you can verify everything before syncing charges to Sage Intacct.
- Each invoice is posted to its corresponding historical period, ensuring audit-ready records and GAAP-compliant revenue recognition.
- The **Property Last Scheduled Charges** field is automatically updated, which prevents the General Scheduled Charges run from re-billing those periods.

## CPI rent increases for Canadian properties

Base rent increases for Canadian properties on Canadian Consumer Price Index (CPI) data sourced from Statistics Canada (StatCan). Except for the specific CPI data that's used, the CPI increase process is the same as the one for U.S. properties.

### Key benefits

- Sage Intacct Real Estate integrates with StatCan to get monthly CPI data for Canada and its provinces so you can align rent increases with the correct regional index for your portfolio.
- For residential properties, provincial rent guidelines apply. For commercial leases, increases are calculated directly from StatCan data.

## CPI rent increases — future period processing

Lease administrators can now run CPI rent increase calculations before the first of the month instead of having to wait until a new period is officially opened.

### Key benefits

- If the required CPI index data is published, you can run the escalation regardless of whether the adjustment date is in the future.
- New charge amounts generated by the CPI process use the Recurring Charge Next Adjustment Date as the effective date, ensuring billing reflects the correct timing.
- When a CPI Next Adjustment Date falls before the Recurring Charge Next Date, the system automatically generates retroactive charges for the gap period.
- Retroactive charges are prorated correctly for partial billing periods, following the property’s configured proration method (30 Day Month or Actual Number of Days). This applies to all standard frequencies: weekly, biweekly, monthly, quarterly, semi-annually, and annually.
- This enhancement is for both CPI US and CPI Canada escalation processes.
