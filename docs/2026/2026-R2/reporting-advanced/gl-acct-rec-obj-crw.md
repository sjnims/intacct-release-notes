# New GL account reconciliations object for Custom Report Writer

[Custom Report Writer Wizard—CRWZ](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=TOC_custom_reports_wizard)

[Add a CRW report](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=Adding_and_editing_custom_reports)

[GL account reconciliations](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=ab-toc-lettrage)

reporting

You can now build custom reports with information from General Ledger account reconciliations using a new object available in the Custom Report Writer (CRW).

To get started, select **GL account reconciliations** as your primary data source when creating a report.

For details about available objects for custom reports, see the [object glossary](https://www.intacct.com/ia/docs/en_US/help_action/Default.htm#cshid=reporting_object_glossary_terms).
